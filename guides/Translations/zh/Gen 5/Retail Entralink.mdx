## 所需工具

- [PokeFinder](/pokefinder)
- [Rambo 的 RNG Reporter](https://ci.appveyor.com/project/Bambo-Rambo/rngreporter/build/artifacts)
- [Mystic Timer](/mystic-timer)

## 了解 C-Gear 乱数

黑/白的 C-Gear 乱数分为三个阶段：

1. **命中初始种子**：决定性格对应的 PID 结果。
2. **命中 C-Gear 种子**：决定个体值。
3. **推进到目标性格**：利用初始种子确保获得正确性格。

进入**连入**时会设置 **C-Gear 种子**，它与初始种子独立，取决于：

- **准确日期和时间**，精确到秒。
- **Delay**，即游戏加载后经过的画面帧数，帧率为 30fps。

## 准备工作

1. 连入之森中要有可进行乱数的宝可梦。建议最初的中央区域中**只放一只**，避免额外推进。
2. 可选：使用 **[Entralinked](https://github.com/kuroppoi/entralinked)**，模拟黑/白的游戏同步服务。
3. 推荐准备 **20-30 颗神奇糖果**。多数连入宝可梦只有 10 级，升级有助于确定准确个体值。如果糖果不足，可以通过第五世代捡拾乱数收集。
4. 站在**没有活动 NPC 的地点**。推荐奇妙大桥，没有 NPC，背景声音也较少，便于通过聒噪鸟验证种子。
5. 至少准备**一只聒噪鸟**，用于验证第五世代的推进数。

## 第一步：寻找目标种子

### 寻找 C-Gear 种子

1. 打开 PokeFinder。
2. 进入第五世代的“Stationary”，切换到“Searcher”标签页。
3. 设置参数。
   - **Method**：IVs C-Gear。
   - **Min Delay**：3000；**Max Delay**：12000，也可以按需调整。
   - **Min Advances**：15；**Max Advances**：20。
   - **IV Filters**：目标个体值。
   - **Date Range**：任意年份，范围为该年 01-01 至 12-31。
4. 点击“Search”。
   - 如果没有结果，提高 Max Delay，或放宽个体值条件。

### 寻找初始种子

1. 打开 RNG Reporter。
2. 复制黑/白配置档案中的数据。
3. 进入 `5th Gen Tools > Entralink Seed Search`。
4. 粘贴 C-Gear 种子。
5. 设置参数。
   - **Year**：与 C-Gear 种子的年份一致。
   - **Max Advances**：60。
   - **Target Nature**：目标性格。
6. 点击“Search”。
   - 如果出现“invalid seed”，换用 PokeFinder 中的另一个种子。
   - 个体值显示为 0 是显示错误，可以忽略。
7. 选择目标初始种子。
   - **DS/Lite/i**：优先选择秒数为 20-30 的结果。
   - **3DS/2DS**：优先选择秒数为 40-50 的结果。

## 第二步：设置工具

### Adjacent Seed Tool：验证初始种子

1. 打开 `5th Gen Tools > Adjacent Seed Tool`。
2. 选择黑/白配置档案。
3. 设置参数。
   - **Method**：IVs (Standard Seed)。
   - **Min & Max Frame**：均为 1。
   - **Seconds ±**：DS/Lite/i 为 1，3DS/2DS 为 3。
   - **Date & Time**：填写 Entralink Seed Search 的结果。
4. 点击“Generate”。
5. 根据聒噪鸟音调确认初始种子。

### Seed to Time：命中 C-Gear 种子

1. 打开“Seed to Time”。
2. 将 C-Gear 种子粘贴到“Seed”栏。
3. 选择“BW (C-Gear Seed)”。
4. 设置参数。
   - **Year**：与初始种子的年份一致。
   - 取消勾选 **Seconds**。
   - 选择黑/白配置档案。
5. 点击右上角的“Generate”。
6. 在结果中找到 Entralink Seed Search 给出的 C-Gear 目标日期和时间。
7. 调整参数。
   - **Delays**：±100，必要时扩大到 ±300。
   - **Seconds ±**：7。
   - **Frame Min**：21；**Frame Max**：31。
8. 点击右下角的“Generate”。

> [!NOTE]
> 每走 128 步，IVRNG 会按照当前队伍中的宝可梦数量推进。

## 第三步：设置 Mystic Timer

1. 打开 **[Mystic Timer](/mystic-timer)**，选择第五世代标签页。
2. 将 Mode 设为“Entralink”。
3. 设置校准值。
   - **DS/Lite/i**：约 -95。
   - **3DS/DSi**：约 -400 至 -500。
4. 根据 Seed to Time 设置 target delay 和 target seconds。
5. 将“Entralink Calibration”设为 315，之后可按需调整。
6. 忽略“Minutes before target: 1”，按照 Adjacent Seed Tool 的结果设置日期和时间。

## 第四步：执行乱数

### 阶段一：命中初始种子

1. 按照 Adjacent Seed Tool 的结果设置主机日期和时间。
2. 启动 Mystic Timer，再确认主机时间设置。
3. 计时器结束时启动游戏，**不要按其他按键**。
4. 等待季节画面自行消失。
5. 听 5-10 次聒噪鸟叫声，参照 Adjacent Seed Tool 的音调验证种子。
6. 如果没有命中，对照相邻种子查找实际结果。

### 阶段二：命中 C-Gear 种子

1. 开启 C-Gear，关闭提示，再按 `X > B` 跳过加载。
2. 点击“Wireless > Entralink”，但**暂时不要按 `A` 或 `B`**。
3. 计时器发声时，按下 `A` 或 `B` 进入连入。
4. 立即捕捉宝可梦，计算准确个体值。

### 阶段三：检查实际种子

1. 打开“Seed to Time”，使用“Search IVs”。
2. 如果没有匹配，将 delay 搜索范围扩大到 ±300 后重试。
3. 如果仍无结果，重新检查日期和时间。
4. 如果已接近目标 delay，暂时不要校准。
5. 如果偏差超过 5，将实际命中值填入 Mystic Timer 并更新。
6. 校准值会相应调整，例如从 0 变为 -90。

> [!TIP]
> 如果结果不稳定，可以适当扩大搜索参数范围。

## 第四步：推进帧数

1. 留意 IVRNG 帧数。
2. 从目标帧数减去 **13**，将结果作为需要推进到的位置。
3. 通过走路推进。队伍中只保留 1 只宝可梦，避免每次推进过多。
4. 到达所需 IVRNG 帧数时，立即与目标宝可梦互动。创建即时存档，再进入战斗。
5. 操作正确后，目标就会具有正确个体值。
6. 要获得目标性格，继续原稿所述的第六步，或读取即时存档重新捕捉宝可梦。

恭喜你！已经获得目标宝可梦了！
