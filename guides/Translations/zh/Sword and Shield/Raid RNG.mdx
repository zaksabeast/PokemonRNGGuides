## 所需工具

- [PokeFinder](/pokefinder) 或 [Leanny 的移动版种子查询器](https://leanny.github.io/seedchecker/index.html)
- 可选，通过自制固件查找种子：[Leanny 的 PKHeX 团体战插件](https://github.com/Leanny/PKHeX_Raid_Plugin) 或 [Zaksabeast 的 CaptureSight](https://github.com/zaksabeast/CaptureSight/releases)
- 可选，通过自制固件自动推进：[Luxray](https://github.com/3096/luxray/releases/tag/0.1.0)

## 基础说明

闪耀护符**不会**影响团体战的异色概率。

## 第一步：获取团体战种子

选择以下一种方式获取种子：

- [使用自制固件查找团体战种子](/retail-swsh-get-seed-with-cfw)。
- [无需自制固件查找团体战种子](/retail-swsh-get-seed-without-cfw)。

## 第二步：寻找目标宝可梦

获得目标巢穴的种子后，使用 PokeFinder 或移动版种子查询器搜索结果。

1. 选择目标巢穴及其稀有度。
2. 根据想要的能力值或是否异色，设置筛选条件。

> [!NOTE]
> PKHeX 团体战插件将当前宝可梦记为推进数 0，而 PokeFinder 将其记为推进数 1。

## 第三步：推进乱数

可以使用以下方式：

- **逐日推进**：没有 Nintendo Switch Online，也没有朋友的 Switch 时使用。
- **对战漏洞**：有 Nintendo Switch Online，或有朋友的 Switch 时使用。
- **Luxray**：仅限自制固件使用的自动推进工具。
- **Arduino**：通过硬件自动推进。本指南不展开介绍，可参考[此推进工具](https://github.com/nnguy132/Switch-Frame-Advancer)。

过程中随时可以重新检查种子，确认是否出现操作偏差。检查当前推进数的方法与第一步获取种子时相同。

### 方法三 A：逐日推进

没有在线服务或第二台 Switch 时，可以使用此方法。

Switch 必须处于本地通信模式，不能使用飞行模式。

1. 与巢穴互动，选择“大家一起挑战”。
2. 搜索队友期间按下 `Home`。
3. 打开“设置”中的“日期与时间”。
4. 将日期向后增加 1 天，点击“OK”。
5. 返回游戏，取消搜索。
6. 退出团体战界面。巢穴应重新发出红光，说明乱数已推进 1 次。
7. 重复操作，直到距离目标还有 3 次推进。

> [!NOTE]
> 每次向后调整日期只能推进一次，调回更早的日期不会推进。月末需要同时调整月份与日期，避免时间倒退。

### 方法三 B：对战漏洞

请在宝可梦中心内进行此操作，其他地点可能导致游戏崩溃。

1. 将 Switch 联网，进入 VS 菜单。
2. 开始对战，让游戏搜索其他玩家。
3. 找到玩家的瞬间，按住 `Home` 开启飞行模式。操作成功后会出现连接错误。
4. 在 Switch 设置中打开“日期与时间”。
5. 将日期向后增加 1 天，点击“OK”。
6. 重复第 5 步，直到距离目标宝可梦还有 3 次推进。
   - 部分玩家会遇到实际推进数超出预期的情况，建议经常检查种子。
   - 检查当前推进数的方法与第一步获取种子时相同。

> [!NOTE]
> 调回更早的日期不会推进乱数，月末需要同时调整月份与日期。

### 方法三 C：Luxray

请在宝可梦中心内进行此操作，其他地点可能导致游戏崩溃。

1. 将日期与时间设置为使用服务器时间。
2. 在浮层菜单中设置需要推进的次数。
3. 点击“Step”，让 Luxray 自动推进。

Luxray 会修改内部服务器时间，也可以用它修正 Switch 时钟。

## 第四步：重置以获得目标宝可梦

当前团体战及接下来两次推进的出场宝可梦已经固定，但第 3 次推进后的种类尚未固定，可以通过重置获得目标宝可梦。

1. 推进到距离目标还有 3 次的位置。
2. 保存游戏。
3. 推进 3 次。
4. 开始团体战，检查是否为目标宝可梦。
5. 如果不是，重置游戏后重新尝试。

| 推进数 | 宝可梦                      |
| ------ | --------------------------- |
| 0      | 当前结果                    |
| 1      | 不是目标                    |
| 2      | 不是目标                    |
| 3      | ✅ 目标宝可梦，种类随机确定 |

## 自然巢穴乱数

每个巢穴都有独立的种子。即使巢穴没有激活，也会随日期逐日推进，而且每次操作会同时推进所有巢穴。

多数玩家会不断投入许愿星块，重置指定巢穴的种子，直到找到理想结果。不过，也可以直接利用各巢穴原有的种子获得异色宝可梦。

重置种子通常是为了在指定巢穴获得理想的性格、异色、个体值等条件。自然巢穴乱数则是从现有种子中挑选，因此对属性和出场种类的控制较少，只推荐用于快速获取异色宝可梦。

此方法可以同时对所有巢穴进行乱数，比只盯着一个巢穴更快。

1. 使用 CaptureSight 的“all den view”，或 PKHeX 团体战插件，寻找距离异色较近的巢穴。
2. 推进到距离异色团体战还有 3 次的位置。
3. 保存游戏。
4. 推进 3 天，检查目标巢穴是否出现红色光柱。
5. 如果没有，重置游戏后重试，直到该巢穴激活。

> [!TIP]
> 可以在任意巢穴投入许愿星块，用该巢穴进行日期推进，省去来回移动的时间。投入星块的巢穴本身也可能有可用的乱数结果！
